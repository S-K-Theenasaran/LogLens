# LogLens

Explainable Machine Learning for Server Log Anomaly Detection.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Drain3
- Streamlit
- SQLite

## Objectives
1. Process server logs.
2. Group similar messages using Drain3.
3. Detect anomalies using Isolation Forest.
4. Compare ML models.
5. Explain anomalies and group incidents.
6. Display results using Streamlit.
